DECK·FORGE — HTML/마크다운을 PPTX(슬라이드·A0 포스터)로

■ 그냥 써보기
   deckforge-standalone.html 을 두 번 눌러 브라우저로 엽니다. 다른 파일 필요 없습니다.
   열쇠말: redpass

■ 사내 PC에서 먼저 확인하기
   이 폴더에서   python3 run-local.py
   브라우저에서  http://localhost:8000

■ GitHub Pages 에 올리기 (이 폴더 통째로)
   git init
   git add -A
   git commit -m "DECK FORGE"
   git branch -M main
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   그 다음 Settings → Pages → Branch: main / (root) 저장.
   1~2분 뒤 https://<계정>.github.io/<저장소>/ 에서 열립니다.

■ 폴더 구조 (이대로 두면 됩니다)
   index.html                    화면
   app.js                        변환기·조판 엔진·편집기
   vendor/pptxgen.bundle.js      PPTX 생성 엔진 (반드시 함께 올릴 것)
   deckforge-standalone.html     위 셋을 합친 단일 파일판
   make_standalone.py            단일 파일판 다시 만들기
   run-local.py                  로컬 확인용 간이 서버
   .nojekyll                     GitHub Pages 가 파일을 건드리지 않게 함
   README.md                     자세한 설명

■ "PPTX 엔진 파일이 없습니다" 가 뜨면
   vendor/pptxgen.bundle.js 가 함께 올라갔는지 확인하세요.
   index.html 옆에 그냥 두어도 앱이 찾습니다. 자세한 내용은 README 5장.
