# DECK·FORGE — HTML을 PPTX로

HTML(또는 마크다운) 문서를 발표용 PowerPoint 파일로 바꾸는 브라우저 작업대입니다.
GitHub Pages 같은 정적 호스팅에 그대로 올려서 씁니다. 서버도, 빌드 도구도, 계정도 필요 없습니다.

문서는 어디로도 전송되지 않습니다. 원본 읽기 · 슬라이드 배치 · PPTX 파일 생성까지 모두 브라우저 안에서 끝납니다.

---

## 1. GitHub Pages에 올리기

**`index.html` 하나만 올리면 됩니다.** PPTX 생성 엔진이 그 안에 들어 있습니다.

1. 저장소를 만듭니다.
2. **Add file → Upload files** 로 `index.html` 을 끌어다 놓고 Commit.
3. **Settings → Pages → Branch: `main` / `(root)`** → Save.
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

명령줄이 편하면:

```bash
git init && git add -A && git commit -m "DECK FORGE"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

### 파일 구성

```
index.html          프로그램 전체 (엔진 내장). 이것만 있으면 동작합니다
START-HERE.txt      한 장짜리 안내
run-local.py        로컬 확인용 간이 서버
.nojekyll           있으면 좋지만 없어도 됩니다
src/index.html      화면과 디자인 (고쳐 쓸 때)
src/app.js          변환기 · 조판 엔진 · 편집기
src/lib/            PPTX 엔진 원본
src/build.py        고친 뒤 실행하면 루트 index.html 을 다시 만듭니다
```

### 왜 파일을 하나로 합쳤나

이전 구조는 엔진을 `vendor/pptxgen.bundle.js` 로 두었는데, GitHub Pages 가 쓰는 Jekyll 은
**기본 설정에서 `vendor` 폴더를 배포에서 제외합니다.** `.nojekyll` 파일은 숨김이라 업로드에서
빠지기 쉽고, 그러면 엔진만 404가 나면서 "PPTX 엔진 파일이 없습니다" 가 떴습니다.
지금은 엔진이 `index.html` 안에 있어 이 문제가 생기지 않습니다. 분리해 쓸 때의 폴더 이름도
`vendor` 가 아니라 `lib` 입니다.

## 2. 열쇠말

처음 열면 열쇠말을 묻습니다. 기본값은 **`redpass`** 입니다.
정적 사이트라 검사는 브라우저 안에서 이뤄집니다. **가벼운 가림막이지 보안 장치가 아닙니다.**
공개 저장소에 올리는 내용은 누구나 볼 수 있다고 가정하세요.

### 열쇠말 바꾸기

새 열쇠말의 해시 두 개를 구해 `app.js` 위쪽 상수를 바꿉니다.

```bash
python3 - <<'PY'
import hashlib
pw = "새열쇠말"
print("KEY_SHA =", hashlib.sha256(pw.encode()).hexdigest())
h = 2166136261
for c in pw:
    h = ((h ^ ord(c)) * 16777619) & 0xFFFFFFFF
print("KEY_FNV =", format(h, "x"))
PY
```

```js
const KEY_SHA = '…';   // https 로 접속할 때 쓰는 값
const KEY_FNV = '…';   // file:// 로 직접 열 때 쓰는 값
```

## 3. 쓰는 법

1. 왼쪽에 HTML을 붙여넣거나 파일을 끌어다 놓습니다. 마크다운을 넣으면 알아서 인식합니다.
2. **슬라이드 만들기** (`Ctrl+Enter`)
3. 가운데에서 결과를 보고, 아래 필름스트립에서 순서를 끌어 바꾸거나 장을 끄고 켭니다.
4. 오른쪽에서 내용·디자인·머리말/꼬리말을 손봅니다.
5. **PPTX 내려받기** (`Ctrl+S`)

### 태그 변환 규칙

| 원본 | 슬라이드 |
|---|---|
| `h1`~`h6` | 제목 · 소제목 |
| `p` | 본문 문단 (`strong` `em` `code` `u` `del` 유지) |
| `ul` `ol` | 글머리 목록, 중첩 단계 유지 |
| `table` | 표 (머리행 색 채움, 줄무늬) |
| `img` `figure` | 그림과 설명글 |
| `pre` `code` | 고정폭 코드 상자 |
| `blockquote` | 인용 상자 |
| `aside class="notes"`, `data-notes` | 발표자 노트 |

### 장 나누는 기준

`h1` / `h1·h2` / `h1·h2·h3` / 가로줄 `hr` / `section`·`article` / 주석 `<!--slide-->` /
직접 지정한 CSS 선택자 / 나누지 않기 중에서 고릅니다. 기본값은 이들을 섞어 판단하는 "알아서"입니다.

내용이 한 장에 넘치면 글자를 먼저 줄이고, 그래도 넘치면 `(계속)` 장으로 이어 붙입니다.

### 판형

가운데 위 판형 상자에서 고릅니다.

| 갈래 | 판형 |
|---|---|
| 슬라이드 | 와이드 16:9 · 16:10 · 표준 4:3 |
| 인쇄 문서 | A4 가로·세로, A3 세로 |
| 포스터 | A0 세로·가로, A1 세로·가로, A2 세로 |

포스터를 고르면 조판 방식 자체가 바뀝니다. 슬라이드 한 장이 포스터의 **구역** 하나가 되어
여러 단에 이어 흐르고, 맨 위에 제목 배너(표지의 제목·부제·발표자)가 붙습니다.

- **단 수** 2~4단. A0 세로는 3단, A0 가로는 4단이 무난합니다.
- **글자 배율** 1.0이 A0 기준 본문 28pt·구역제목 36pt·큰제목 100pt로, 학회 포스터의 표준 크기입니다.
- **한 장에 꽉 채우기** 단 수와 배율을 함께 탐색해 한 장에 가장 알차게 맞춥니다.
- 내용이 넘치면 다음 쪽으로 이어집니다. 인쇄 전에 쪽수가 1인지 확인하세요.
- 여백이 많으면 상태줄이 알려 줍니다.

인쇄용 PDF는 **PDF로 인쇄**에서 대상을 "PDF로 저장"으로 고르면 됩니다. 용지 크기는 판형에 맞춰 자동 지정됩니다.
PPTX로 내려받아 인쇄소에 맡겨도 됩니다. A0(841×1189 mm)은 PowerPoint 슬라이드 크기 한계 안에 있습니다.

## 4. 알아둘 점

- **그림**: 다른 도메인의 그림 주소는 브라우저의 교차출처 제한 때문에 PPTX에 담기지 못할 수 있습니다.
  HTML 안에 `data:` 형식으로 넣거나, 그림을 같은 폴더에 두고 파일로 여는 방법이 확실합니다.
  가져오지 못한 그림은 자리만 남고, 몇 개가 빠졌는지 상태줄에 알려 줍니다.
- **글꼴**: 파일에는 글꼴 이름만 들어갑니다. 발표할 PC에 없는 글꼴을 고르면 다른 글꼴로 대체됩니다.
  사내 공용이라면 `맑은 고딕`이 가장 안전합니다.
- **미리보기와 결과**: 배치 계산을 미리보기와 PPTX가 같은 함수로 공유하므로 위치는 일치합니다.
  다만 줄바꿈은 PowerPoint의 실제 글꼴 폭에 따라 한두 줄 달라질 수 있습니다.
- **저장**: 작업 중인 내용은 이 브라우저에만 자동 저장됩니다. 다른 PC로 옮기려면 `작업 저장(.json)`을 쓰세요.

## 5. "PPTX 엔진 파일이 없습니다" 가 뜰 때

루트의 단일 파일 `index.html` 을 쓰고 있다면 이 막대는 뜨지 않습니다. 떴다면 `src/` 쪽 파일을
직접 열고 있는 경우입니다. 앱은 다음 순서로 엔진을 찾고, 마지막에는 인터넷에서도 받아 봅니다.

```
lib/pptxgen.bundle.js → pptxgen.bundle.js → lib/pptxgen.min.js → pptxgen.min.js
→ vendor/… → js/… → assets/… → jsDelivr (인터넷)
```

어떤 위치를 시도했는지는 개발자도구 콘솔(F12)에 찍힙니다. 해결 방법:

1. 루트 `index.html`(단일 파일판)을 씁니다. 가장 확실합니다.
2. 분리해 쓰려면 `pptxgen.bundle.js` 를 `lib/` 안이나 `index.html` 옆에 둡니다.
   `vendor` 라는 폴더 이름은 GitHub Pages 에서 피하세요.
3. 급할 때는 막대의 **파일 직접 고르기** 로 지정하면 그 자리에서 됩니다.

엔진이 없어도 변환·미리보기·편집·PDF 인쇄는 그대로 됩니다. 막히는 것은 PPTX 내려받기뿐입니다.

## 6. 자체 검증

위쪽 **자체 검증** 단추를 누르면 18개 항목이 실행됩니다. 장 나누기, 중첩 목록, 강조 보존, 표,
발표자 노트, 마크다운 변환, 도형이 슬라이드 밖으로 나가지 않는지, 넘침 분할, 모든 제목 장식에서의
경계 검사, A0 포스터 조판(쪽수·단 수 반영·글자 크기), 열쇠말 검사, 그리고 실제 PPTX 파일이 만들어지는지까지 확인합니다.
코드를 고친 뒤에는 이 단추를 먼저 눌러 보세요.
